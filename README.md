# Smit Salunkhe — Portfolio V1

A personal portfolio website showcasing my journey as a Computer Engineering student, my technical skills, certifications, internship experience, and selected web development projects.

Designed with a futuristic, terminal-inspired interface, this portfolio reflects my interest in frontend development, interactive web experiences, and software engineering.

## 🌐 Live Website

[**View Portfolio →**](https://salunkhesmit.github.io/portfolio_v1/)

## ✨ Features

- **Interactive Intro** — Terminal-inspired initialization and loading sequence.
- **About Me** — Introduction, educational background, development journey, and career aspirations.
- **Technical Skills** — Categorized skills across frontend, backend, programming, databases, AI & ML, and tools.
- **Certifications** — Interactive showcase of certifications and learning achievements.
- **Internship Experience** — Overview of professional web development internship experience.
- **Projects & Work** — Selected projects with descriptions, features, technology stacks, and live demos.
- **Interactive Terminal** — A functional terminal-style interface for exploring the portfolio.
- **Contact Section** — Direct links to GitHub, LinkedIn, and email.
- **Responsive Interface** — Designed to provide an accessible experience across different screen sizes.
