# Portfolio V1

A personal portfolio featuring an interactive dark-themed interface, custom visual effects, and immersive 3D elements.

## Overview

Portfolio V1 is the first version of my personal developer portfolio. It brings together selected projects, technical skills, and personal information through a visually interactive experience.

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Bootstrap 5
- Three.js

## Features

- Responsive layout
- Interactive 3D elements
- Custom visual effects and animations
- Project showcase
- Skills and profile sections
- Interactive footer elements

## Project Status

**Version:** 1.0

This is the first iteration of the portfolio. Further improvements and additions may be introduced in future versions.
